# Match Quality Baseline

## Objective

Evaluate the quality of the AI job recommendation system before introducing monetization features.

## Metrics

- Total Students Evaluated
- Total Jobs Available
- Match Quality Baseline
- Recommendation Status

## Technologies Used

- Python
- Flask
- Pandas
- REST API

## Outcome

The evaluation API records the baseline quality of the recommendation engine. This baseline can be compared with future versions after monetization features are introduced.

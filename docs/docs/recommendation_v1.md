# Recommendation Engine v1

## Objective

Design the first version of the recommendation engine for matching students with suitable job opportunities.

## Features

- Skill matching
- Match score calculation
- Job ranking
- Recommendation generation
- REST API support

## Technologies

- Python
- Flask
- JSON
- REST API

## Outcome

Recommendation v1 compares student skills with job requirements, calculates a match score, ranks jobs, and provides recommendation details through an API.

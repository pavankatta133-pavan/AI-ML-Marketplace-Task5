# Item Bank Quality Support

## Objective

Identify weak-quality assessment questions and make them available for administrator review.

## Features

- Question quality evaluation
- Weak item detection
- Admin review flags
- Quality reporting
- REST API support

## Technologies

- Python
- Flask
- JSON
- REST API

## Outcome

The system automatically identifies weak questions based on usage and accuracy metrics, flags them for review, and exposes the results through an API for administrators.

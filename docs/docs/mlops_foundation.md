# MLOps Foundation

## Objective

Establish the initial MLOps infrastructure by implementing a basic model registry and feature store.

## Features

- Model Registry
- Feature Store
- Model Version Tracking
- REST API Integration

## Technologies

- Python
- Flask
- JSON
- REST API

## Outcome

The project includes a basic model registry for managing model versions and a feature store for storing reusable machine learning features, providing the foundation for future MLOps workflows.

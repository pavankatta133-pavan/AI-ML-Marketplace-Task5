# Drift Monitoring & Retraining Pipeline

## Objective

Monitor recommendation quality over time and automatically trigger retraining when model drift is detected.

## Features

- Drift detection
- Historical vs current score comparison
- Automatic retraining trigger
- Drift reporting
- REST API support

## Technologies

- Python
- Flask
- JSON
- REST API

## Outcome

The system continuously monitors recommendation performance, detects model drift, and activates a retraining pipeline when performance degradation exceeds the defined threshold.

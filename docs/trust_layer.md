# AI Trust Layer - Proctoring Hardening

## Objective

Reduce false-positive proctoring alerts by confirming suspicious behavior over multiple consecutive events instead of reacting to a single event.

## Features

- False-positive reduction
- Consecutive violation threshold
- Proctoring hardening
- REST API integration

## Technologies

- Python
- Flask
- REST API

## Outcome

The trust layer improves the reliability of AI proctoring by reducing unnecessary alerts and confirming violations only after repeated suspicious events.

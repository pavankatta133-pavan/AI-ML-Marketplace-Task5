# Relevance Regression Check

## Objective

Verify that the monetization and paywall changes did not reduce the quality of job recommendations.

## Features

- Recommendation quality validation
- Conversion quality check
- Regression detection
- REST API support

## Technologies

- Python
- Flask
- Pandas
- REST API

## Outcome

The system compares recommendation quality before and after monetization and confirms whether any relevance regression has occurred.
